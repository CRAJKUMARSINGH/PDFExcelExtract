PDF to Excel/Word Converter - User Guide
=======================================

Overview
--------
This solution converts scanned PDF documents to editable Excel and Word formats while preserving formatting and maintaining statutory accuracy for legal documents.

Files Included
--------------
- complete_pdf_converter.py - Main application with GUI
- run_converter.bat - Runs the converter application
- enhanced_installer.bat - Installs all required components
- requirements.txt - Lists Python packages needed
- README.md - Detailed documentation

Step-by-Step Setup
------------------

1. Install Required Components
   Double-click on enhanced_installer.bat
   - The script will check for Python and required packages
   - If Tesseract OCR is missing, you'll get installation instructions
   - Follow the prompts to complete installation

2. Install Tesseract OCR (if needed)
   If prompted during installation:
   1. Download Tesseract from: https://github.com/UB-Mannheim/tesseract/wiki
   2. For Windows, download "tesseract-ocr-w64-setup-v5.x.x.exe"
   3. During installation, check "Add to PATH"
   4. Restart your computer after installation

3. Run the Converter
   Double-click on run_converter.bat
   - The GUI application will open
   - Select your input folder containing PDF files
   - Select or confirm the output folder
   - Choose conversion options (Excel, Word, or both)
   - Click "Start Conversion"

Features
--------
- Batch processing of multiple PDF files
- Progress tracking with visual indicator
- Detailed logging of conversion process
- Preservation of document formatting
- Support for legal/statutory document accuracy

Best Practices for Scanned Documents
------------------------------------
1. Use high-resolution scans (300 DPI or higher)
2. Ensure good contrast between text and background
3. For legal documents, always review converted files for accuracy
4. Save original PDFs as backup

Troubleshooting
---------------
- If Python is not recognized: Reinstall Python with "Add to PATH" option
- If conversion fails: Check that Tesseract is properly installed and in PATH
- For poor conversion quality: Improve scan quality or adjust Tesseract settings
