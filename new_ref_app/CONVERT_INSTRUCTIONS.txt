HOW TO CONVERT ALL PDF FILES TO WORD AND EXCEL
============================================

Simple Steps:
------------

1. DOUBLE-CLICK on "convert_all_pdfs.bat"
   - This will automatically install required software
   - Then convert all PDF files in this folder
   - Both Word (.docx) and Excel (.xlsx) versions will be created

2. WAIT for the process to complete
   - You'll see progress messages in the window
   - This may take a few minutes depending on the number of files

3. CHECK the "Converted_Files" folder
   - All converted documents will be there
   - Each PDF will have both a .docx and .xlsx version

Technical Notes:
---------------

- The Word documents will preserve paragraph structure
- The Excel files will try to preserve table-like data
- For scanned PDFs with images only, text extraction may be limited
- For best results with scanned documents, use high-resolution scans
