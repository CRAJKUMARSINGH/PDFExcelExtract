HOW TO CONVERT PDFs TO WORD AND EXCEL
===================================

EASY STEPS:
-----------

1. DOUBLE-CLICK on "convert_and_save.bat"
   - This will automatically install required software
   - Then convert all PDF files in this folder
   - Output will be saved in the "output" folder

2. WAIT for the process to complete
   - You'll see progress messages in the window
   - This may take 2-5 minutes depending on how many files you have

3. CHECK the "output" folder
   - All converted documents will be there
   - Each PDF will have both a .docx (Word) and .xlsx (Excel) version

--------------------

- Preserves document structure where possible
- Saves all output in the "output" folder

NEED HELP?
----------

If you encounter any issues:

1. Make sure Python is installed on your computer
   - Download from: https://www.python.org/downloads/
   - During installation, CHECK "Add Python to PATH"

2. Make sure you're connected to the internet
   - Required packages will be downloaded automatically

3. If problems persist, contact technical support
